# Kunal Mishra — Enterprise AI Architect & Quantitative Researcher

> Single-page portfolio built with React, Vite, Tailwind CSS, and Recharts, showcasing over 14 years of enterprise technology leadership, multi-agent systems, ontology knowledge graphs, and empirical econometrics.

Live URL: [https://drkunalmishra.github.io/](https://drkunalmishra.github.io/)

---

## 🚀 Core Features

- **Abstract Neural Network Hero Architecture**: Sleek visual canvas with real-time KPI metrics and executive profile.
- **Governed Multi-Agent Intelligence Blueprint**: 4-stage pipeline modeling Databricks/Snowflake Lakehouse &rarr; Timbr/Purview Semantic Graph with ABAC &rarr; LangGraph/CrewAI Agentic Orchestration &rarr; Gurobi/OR-Tools Optimization with MLflow verification.
- **Recharts Competence Convergence Matrix**: Interactive Radar Chart & Technology Stack breakdown.
- **Econometrics & Empirical AI Lab**: Applied econometrics, financial volatility modeling (GARCH), time-series analysis, and causal inference formulations.
- **Career Timeline (14+ Years)**: Filterable journey across NTT DATA, ORMAE, Tech Mahindra, JIFFY.ai, CRG Solutions, Tracxn, Infosys, and Huawei Technologies.
- **Dual Doctoral Track**: Walsh College (DBA AI) & ISBR Business School (FPM Analytics).

## 🛠️ Development & Build

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build production bundle
npm run build

# Preview production build locally
npm run preview
```

---

## 🌐 Deployment

Automated via GitHub Actions on push to `main` (`.github/workflows/deploy.yml`).
Alternatively, deploy using the `gh-pages` script:

```bash
npm run deploy
```
